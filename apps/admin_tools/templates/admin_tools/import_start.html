How it works

  • The first row is the column names (any order; capitals and spaces don't matter). Unknown columns are ignored.
  • A row that matches an existing item is updated: an activity with the same name, an event with the same name and start date. Blank cells keep the existing value.
  • Categories, countries, regions, cities and activities are matched by name. An event city that isn't in the catalogue is kept as a typed town for staff to link later.
  • Yes/no columns take yes, no, true, false, 1 or 0. Dates: 2027-09-18 (or 9/18/2027). Times: 20:00 or 8:00 PM. Months: “Sep, Oct” or “9, 10”.
  • Imported items are published straight away.
