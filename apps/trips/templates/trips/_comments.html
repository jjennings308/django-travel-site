{% comment %} Comment thread for one object. Included with an explicit ``comments`` list rather than queried in the template, so the page's query count is a known number. The caller is responsible for prefetching; a bare ``comment_set.all`` here would be one query per day. Renders nothing when there are no comments *and* the reader cannot add one — a viewer with nothing to say should not be shown an empty heading and an empty list on every day of the trip. Usage: {% include "trips/_comments.html" with comment_kind="trip" comment_pk=trip.pk comments=trip_comments can_comment=True %} {% endcomment %} {% if comments or can_comment %}
