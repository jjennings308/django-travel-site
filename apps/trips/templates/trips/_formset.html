{% comment %} One inline formset as a stack of collapsible cards. Five of these on the trip edit page, so it is a partial rather than markup copied five times. It used to be a table, but lodging and transport are ten inputs wide and the table scrolled sideways; a card per row puts the fields in a two-column grid instead. Each row is a
: an existing row shows a one-line summary (`row.instance`, whose __str__ reads only its own columns, so no queries) and opens to edit; the blank extra row is the "Add" control. A row with errors is rendered open. A closed
still submits its inputs, and Django formset forms carry no `required` attribute, so a collapsed row cannot block a submit. `DELETE` is excluded from the field loop. Django adds it as a *visible* field on every form, so looping `visible_fields` naively renders the remove checkbox once in the body and again in the row header — two checkboxes with the same name, and clicking either deletes. Rows are rendered server-side. A formset that needs JavaScript to add a row is a formset that cannot be used without it, and this app has none: `extra=1` always leaves one blank row, and an untouched blank row is skipped on save rather than written as a row of NULLs. {% endcomment %}
