{% comment %} Renders a form's visible fields with per-field help, but skips fields a caller lists as hidden. The `not hide_fields or` matters: without it, a caller that passes no hide_fields renders *nothing* (`x not in ` is an error, which the template engine turns into False). Django has no built-in "render everything except these", and the trip form uses `as_p` while the day form needs a rendered hint under `travelers`. This partial exists so both get the same markup, and so a field added to a form appears without a template edit. {% endcomment %}
